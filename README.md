# My LeetCode Journey

This repository is basically a record of my LeetCode journey.

I'll use it to keep track of what I actually do each day — the problems I solve, the things I learn, the mistakes I make, and the progress I make over time.

The main purpose is simple: **stay consistent, keep learning, and get better at problem solving.**

I'll be updating this repository regularly with my daily progress and solutions.
